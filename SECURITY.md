# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public GitHub issue.

Send a private report to **343397495@qq.com** with:

- the affected version or commit;
- reproduction steps or a proof of concept;
- the expected impact;
- any suggested mitigation, if available.

Please use the subject prefix `[Aix-DB Security]`. Do not include real user
data, production credentials, or other secrets in the report. We will
acknowledge receipt and coordinate remediation and disclosure with the
reporter.

For ordinary bugs and feature requests, continue to use GitHub Issues.
